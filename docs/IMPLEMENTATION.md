The checked-in client is an ordinary Mini Program (`compileType: "miniprogram"`) with WXML/WXSS pages. The client can use the local HTTP backend or the optional WeChat Cloud Development backend. Automated tests cover the cloud game service, concurrent acknowledgements, idempotency and client cloud-action mapping. Account-backed DevTools compilation, real-device rendering and four-phone multiplayer still require Mini Program validation. Public release also depends on the game-category requirements and review.

The implementation includes the requested core workflows. The goal remains open for native/account/device validation. Its external prerequisites are a Mini Program AppID, a configured HTTPS backend, server-side AppSecret configuration, and WeChat DevTools/devices. The documented no-timer policy can wait indefinitely for a disconnected player, and wall commitments establish consistency rather than fair seed selection.
