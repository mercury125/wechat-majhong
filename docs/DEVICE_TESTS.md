# Native validation still required

The remaining question is whether the native client compiles and works correctly in WeChat, with your account, backend domain, and iOS/Android devices. The Node tests do not establish this. No items below have been executed in this environment.

## Setup

Follow [Build, upload and publish](../README.md#build-upload-and-publish) for the current client package, backend deployment, account membership, legal domains and experience-version upload. The repository uses an ordinary Mini Program project (`compileType: "miniprogram"`). Confirm the game-category requirements before public submission.

Run `npm run build`, import the repository root into WeChat DevTools, and configure your real Mini Program AppID. For Cloud Development, set `cloudEnv` and `assetBase` in `miniprogram/config.js`, create the database collections and deploy `cloudfunctions/api`. For local HTTP mode, configure the HTTPS backend and keep domain checks enabled. Use four distinct authenticated players.
